Що потрібно

Нічого встановлювати окремо не треба

Раніше застосунок вимагав доставити ffmpeg через термінал. Більше ні — звук розкодовується вбудованими засобами macOS.

  • ✓ Без термінала й Homebrew Достатньо перетягнути застосунок у Applications.
  • ✓ Без акаунтів і підписок Реєстрації немає, застосунок безкоштовний.
  • ✓ Без інтернету після налаштування Один раз завантажується мовна модель — далі все рахується офлайн.

Перший запуск

Чотири кроки, один із них неочевидний

  1. 01 Відкрий завантажений файл і перетягни wave у Applications. Звичайне вікно з іконкою та стрілкою — просто перетягни.
  2. 02 Натисни на wave правою кнопкою → Open → ще раз Open. Саме правою кнопкою, не подвійним кліком. Подвійний клік покаже попередження без кнопки «відкрити», і здасться, що застосунок зламаний.

    macOS скаже, що розробник невідомий — це нормально. Застосунок не має платного сертифіката Apple, тому система перестраховується. Через правий клік з'явиться кнопка Open. Один раз, далі запускатиметься звичайно.

  3. 03 Зайди в Settings → Models і завантаж модель. Turbo — найкращий баланс, 575 МБ. Якщо інтернет повільний, візьми Tiny на 31 МБ, щоб спробувати. Прогрес видно у вікні.
  4. 04 Записуй або перетягни файл — і тисни транскрибувати. Далі інтернет не потрібен. Дозволи на мікрофон і запис екрана система попросить сама, коли вони знадобляться.
